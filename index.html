เลือกขอบเขตให้เหมาะกับงาน

แต่ละโหมดตรวจไม่เหมือนกัน Luna Guard จะแสดงขอบเขตและปัญหาที่พบในผลสแกน

01FOCUSED

Auto file scan

ตรวจ Downloads, Temp, AppData และ Startup แบบอ่านอย่างเดียว รองรับ archive ที่ใช้งานได้

  • เหมาะสำหรับการตรวจไฟล์ทั่วไป
  • ไม่ตรวจ process, memory หรือ network
02EXPANDED

Quick scan

ตรวจโฟลเดอร์พื้นฐาน พร้อม process และ memory, persistence, network/DNS และ PowerShell history

  • ตรวจสัญญาณจากระบบเพิ่มเติม
  • สิทธิ์ Windows อาจจำกัดบางรายการ
03DEEP DRIVE

สแกนไดรฟ์ C:

พยายามตรวจทุกไฟล์ที่เข้าถึงได้ในไดรฟ์ C: โดยไม่มีเพดานรวมจำนวนไฟล์หรือเวลา

  • ใช้โปรไฟล์ archive แบบ Deep ที่มีขอบเขต
  • junction และรายการที่เข้าถึงไม่ได้ทำให้ผลไม่ครบ

iการสแกนไดรฟ์เต็มอาจใช้เวลานานมาก และไม่สามารถรับประกันการเข้าถึงทุกไฟล์ได้ ดูรายละเอียดขอบเขต archive ในคู่มืออ่านคู่มือ ↗
