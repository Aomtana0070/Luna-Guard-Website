PROJECT SNAPSHOT

An existing codebase to build on

Luna Guard is an on-demand Windows file scanner with a dashboard, local hash/IOC database, YARA, file analysis, and quarantine that verifies SHA-256 before restore. A limited-scope Android companion app is also available.

IMPORTANT TRANSPARENCY

Scope and rights need verification

The project is pre-revenue and is not a replacement for Microsoft Defender or a full endpoint protection platform. The repositories currently have no LICENSE file; YARA rule licensing and the provenance of some assets need confirmation before transfer. Dependencies remain under their respective owners’ licenses, and threat-intelligence provider terms do not transfer automatically.
